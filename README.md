# JAVA_ 📘

A collection of Java programs written while learning and practicing core Java concepts — covering OOP, exception handling, collections, multithreading, enums, lambdas, and more. This repo serves as a personal reference/notes repository built through hands-on coding.

## 📂 What's Inside

### Object-Oriented Programming
- `inheritance.java`, `parant.java` — Inheritance basics (parent-child class relationships)
- `Mammal.class`, `animal.class`, `Dog.class` — Class hierarchy examples
- `static_key.java` — Usage of the `static` keyword

### Arrays & Collections
- `array.java` — Single-dimensional arrays
- `twodarray.java` — Two-dimensional arrays
- `threedarray.java` — Three-dimensional arrays
- `arrlt.java` — ArrayList / Collections usage
- `varibale_argument.java` — Variable arguments (varargs)

### Strings & Data Types
- `armString.java` — String manipulation
- `primitiveNonprimitive.java` — Primitive vs non-primitive (reference) data types
- `typeConversion.java` — Type casting / conversion
- `wrapperClass.java` — Wrapper classes
- `autoAndunboing.java` — Autoboxing and unboxing

### Exception Handling
- `exception.java` — Custom/standard exception handling
- `us_df_exception.java` — User-defined exception example

### Functional Programming
- `lamda.java` — Lambda expressions
- `enumday.java` — Enum usage

### Concurrency
- `thred.java` — Multithreading basics

### Miscellaneous
- `bitwise.java` — Bitwise operators
- `commandLine.java` — Command-line arguments in Java
- `database.java` — JDBC / database connectivity basics
- `Sw_ing.java` — Java Swing (GUI) example
- `main.java`, `demo.java`, `multiple.java` — General practice/demo files
- `emp.java`, `student.java`, `job.java`, `bill.java` — Sample class-based mini programs (Employee, Student, Job, Billing models)

> Note: `.class` files present in the repo are compiled bytecode outputs of the corresponding `.java` source files.

## 🚀 How to Run

1. Clone the repository:
```bash
   git clone https://github.com/Rahim-Kamran/JAVA_.git
   cd JAVA_
```
2. Compile any Java file:
```bash
   javac FileName.java
```
3. Run it:
```bash
   java FileName
```
